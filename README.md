# Flex Grow

Năm flex item có width 100px, item thứ hai flex-grow 1; bốn item khác grow mặc định 0.

## Chạy
Mở index.html trong trình duyệt. Ví dụ cố định kích thước có khung cuộn ở màn hình nhỏ; các bài bố cục có media query.

## Đề bài
https://internship.codegym.vn/learning/18/activity/1509

## Kiểm tra
Đã mở 375, 768, 1440 px và đối chiếu direction/wrap/basis/grow cùng vị trí, kích thước item trong trình duyệt. Ảnh result.png ghi lại ví dụ chạy thực tế.
